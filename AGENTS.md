# AGENTS.md - Neovim Configuration Repository

## Overview
Personal Neovim configuration written in Lua using [lazy.nvim](https://github.com/folke/lazy.nvim) as plugin manager. Main entry point: `nvim/.config/nvim/init.lua`.

## Build/Lint/Test Commands

### Reloading Configuration
```bash
:source %           # Reload current file
<leader><leader>    # Keybinding to reload current file
```

### Lua Syntax/Linting
```bash
:LspStart          # Start LSP diagnostics manually
:checkhealth lsp   # Verify LSP configuration
nvim --headless -c 'lua require("GB")' -c 'q'  # Test config headless
```

### Plugin Management (in Neovim)
```bash
:Lazy              # Open Lazy UI
:Lazy sync         # Sync all plugins
:Lazy clean        # Remove unused plugins
:Lazy update       # Update all plugins
```

### Shell Scripts (scripts/)
```bash
./scripts/testRunner.sh     # Test zsh installation
./scripts/testscript.sh     # Bash array test
./scripts/install-packages.sh
```

## Code Style Guidelines

### Imports
- Use `require()` for module imports (e.g., `require('GB.lsp')`)
- Modules under `lua/` directory
- Avoid Lua's deprecated `module()` pattern

### Formatting
- 4 spaces for indentation (soft tabs)
- No trailing whitespace
- Use `[[ ]]` for multiline strings
- `vim.api.nvim_create_autocmd` for autocommands (not deprecated `autocmd`)

### Naming Conventions
- **Variables**: snake_case (e.g., `local venv_path`)
- **Constants**: UPPER_SNAKE_CASE (e.g., `local LSP_ICONS = {...}`)
- **Files/Modules**: snake_case (e.g., `lsp.lua`, `autocomplete.lua`)
- **Augroups**: descriptive names (e.g., `'highlight-yank'`)
- **Leader key**: spacebar (`vim.g.mapleader = " "`)

### Keybindings
- Use `vim.keymap.set({mode}, keys, func, opts)` with `{desc}` field
- Modes: `'n'` (normal), `'v'` (visual), `'i'` (insert), `'x'` (visual block)
- Prefix user keybindings with `<leader>`

### Error Handling
- `pcall(require, 'module')` for optional dependencies
- `vim.fn.expand()` for path operations
- `vim.env` for environment variables
- Graceful degradation: `enabled = false` for optional plugins

### Vim Options
- Use `vim.opt` (not `vim.o`)
- `vim.api.nvim_create_augroup()` for augroup management
- `vim.env.VIRTUAL_ENV` for Python venvs

### LSP Configuration
- `vim.lsp.enable({...})` to enable language servers
- Define icons tables for completion kinds
- `vim.diagnostic.config()` for diagnostics
- Autocommands use `'LspAttach'` event for LSP keybindings

### Plugin Configuration
- Return tables for lazy plugin specs
- Plugin specs include `ft` for filetype-specific plugins
- Disabled plugins: `enabled = false`

## File Structure
```
nvim/.config/nvim/
├── init.lua              # Entry point
├── lazy-lock.json        # Auto-generated by Lazy
├── lua/
│   ├── GB/              # Main config modules
│   │   ├── init.lua, lsp.lua, set.lua, remap.lua
│   │   ├── lazy/        # Plugin specs
│   │   └── incons.lua   # Icons
│   └── utils/           # Utility modules
├── lsp/                  # LSP server configs
├── plugin/               # Plugin-specific configs
└── after/                # Filetype plugins
```

## Comments
- `--` for single-line comments
- Add `desc = '...'` for autocommands and keybindings
- Remove commented-out code unless debugging

## Development Workflow
1. Make changes to Lua files
2. Reload with `:source %` or `<leader><leader>`
3. Verify in Neovim
4. `lazy-lock.json` updates automatically

## Key Dependencies
- Neovim 0.9+ (0.10+ recommended)
- lua-language-server (luals)
- lazy.nvim
- ripgrep, fd (for Telescope)

## Notes
- This is a personal config - prioritize consistency
- Test plugin changes before committing
- Keep `:checkhealth` clean and passing

## Testing Single Configuration Modules
To test individual modules without loading the full config:
```bash
nvim -u NONE -c 'lua require("GB.set")' -c 'q'  # Test set.lua only
nvim -u NONE -c 'lua require("GB.remap")' -c 'q'  # Test remap.lua only
```

## Common Patterns

### Creating Autocommands
```lua
vim.api.nvim_create_autocmd('EventName', {
    pattern = '*.lua',
    group = vim.api.nvim_create_augroup('group-name', { clear = true }),
    callback = function(ev)
        -- your logic
    end,
    desc = 'Description of what this does'
})
```

### Defining Keybindings
```lua
vim.keymap.set('n', '<leader>ff', function()
    -- your implementation
end, { desc = '[F]ind [F]iles' })
```

### Checking Optional Dependencies
```lua
local status_ok, telescope = pcall(require, 'telescope')
if status_ok then
    telescope.setup({})
end
```
